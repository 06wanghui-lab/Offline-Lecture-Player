# Offline Lecture Player

A simple offline HTML player I use for watching lecture recordings with synced Zoom transcripts and captions.

## How to use

1. Download or open `zoom_style_offline_transcript_player_with_subtitles.html`.
2. Open it in a web browser.
3. Select a video file.
4. Select the matching Zoom `.vtt` transcript.

Everything runs locally in the browser. Videos and transcripts are not uploaded anywhere.

## Notes

- Supports common video formats such as MP4, MOV, M4V, and WebM.
- Includes searchable transcripts and captions.
- Intended mainly for my personal use.
- Video and transcript files are not included in this repository.
